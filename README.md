## Weekly Task Goals 
==> This feature provides a sum total(numerical value) of weekly goal (dailyGoal multiplied by 5 workdays) and weekly bonus tasks. For instance, if the daily taks goals are 5 with weekly bonus task of 5, the total task goals is calculated as 30. 
weekly goal = daily task goal * 5 = 5 * 5 = 25 
total task goal = weekly goal + weekly bonus task = 25 + 5 = 30
